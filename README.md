# F1 Dashboard

An interactive Formula 1 dashboard built with **Streamlit**, visualizing data from the [F1 Data Pipeline](https://github.com/el-03/f1-data-pipeline) that I created for an E2E data project.

Explore how drivers and teams have performed throughout the **Hybrid V6 Turbo Era (2014–present)**.

---

## 🎯 What You Can Explore
- Drivers’ and Teams’ **Championship Standings**
- **Points Progression** across rounds and seasons
- Quick stats: **Most Wins, Poles, DNFs, and Overtakes**
- Filter by **season** and **top performers**

---

## ⚙️ Tech Stack
**Streamlit**, **PostgreSQL**, **Altair**, **Pandas**, **Python**

---
